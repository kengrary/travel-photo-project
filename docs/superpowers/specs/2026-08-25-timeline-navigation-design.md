# 时间轴导航优化设计

日期：2026-08-25
状态：已确认

## 背景

时间轴按「年 → 月 → 地点」纵向聚合，照片逐年增多后页面很长，存在四个痛点：

1. 难跳转到某一年/月
2. 难找到某个地点
3. 滚动时不知道自己在哪
4. 年份太多显示拥挤

数据规模：2830 张照片、9 年（2018–2026）、89 个地点组。

## 方案：折叠时间轴 + 侧边年份索引 + 地点预览

### 页面结构

```
┌ 页头（地点搜索框 + 全部展开/收起按钮）        ┐
├───────────────┬──────────────────────────────┤
│ 年份索引条     │ 时间轴主体                     │
│ (sticky 右/左) │  2026 [chip][chip][chip]...  │ ← 收起态
│  2026 ●       │  2025 [chip][chip]...         │
│  2025         │  2024 ▶ (展开: 月份→地点→照片)  │
│  2024 ●高亮    │  ...                          │
└───────────────┴──────────────────────────────┘
```

### 核心交互

1. **年份默认收起**：`expandedYears: Set<number>` 支持多选展开。收起态显示年份节点 + 该年地点 chip 行（地点名·张数）。点年份标题展开/收起，点 chip 直接定位到该地点照片。
2. **侧边年份索引**：`position: sticky`，列出年份 + 各年照片数；用 IntersectionObserver 随滚动高亮当前所在年份；点击年份展开并滚到该年。
3. **地点搜索**：输入防抖 300ms，匹配 province/city/county 拼接串；下拉结果 `大理 · 2024年 · 198张`，点击定位。定位动作 = 展开该年 → 展开该地点 → scrollIntoView + 高亮闪烁动画。
4. **定位统一逻辑**：`locatePlace(year, month, key)` 供 chip / 搜索结果 / 全部展开共用。
5. **展开的地点照片**：沿用现有单地点展开（一个 key）。
6. **全部展开/收起** 切换按钮放页头。

### 数据流

- 全部前端派生，无 API 改动。
- 状态：`photos`（不变）、`expandedYears`（Set）、`expandedPlace`（地点 key）、`scrollTarget`（待定位锚点）、`searchText`。

### 样式

- 沿用现有设计语言（--surface / --line / --vermillion、发丝线边框圆角）。
- 地点 chip 加 hover 反馈；定位高亮用闪烁动画淡出。

### 验证

- 无前端测试框架，`npm run build` 编译通过 + `npm run dev` 手动验证交互。
